# AI Repo Library

A curated index of public GitHub repositories that can help me build research, data science, and AI skills.

This is a **directory of sources**, not a copy of other people's code. Each entry should explain why a repository is useful and where an AI assistant should look first.

## How to use this library with ChatGPT or Claude

1. Find relevant entries in [repos.md](repos.md).
2. Open the linked source repository and inspect the files named in the entry.
3. Use those sources to help with the task or draft a skill tailored to my workflow.
4. Cite the repositories and files used, distinguish source guidance from recommendations, and check the source license before reusing substantial material.

The assistant needs GitHub access or the relevant links/files shared in chat. A link in this library does not automatically grant access.

## Curation rules

- Add repositories that support a real learning or research need.
- Prefer maintained projects, clear documentation, practical examples, and trustworthy sources.
- Record the specific files or folders worth reading; do not expect an assistant to inspect an entire repository.
- Keep descriptions and notes in my own words. Link to original work and respect its license.
- Do not add private lab material, restricted course content, or participant data.

## Add a repository

Use the short entry template in [repos.md](repos.md). Keep this index small and useful; no database or automation is needed to start.
