# AI Repo Library

I keep public GitHub projects here when I want to learn from them or use them in research. Each note says why I saved the project and where I plan to start.

## Using this list with ChatGPT or Claude

Share this repository with your assistant and ask it to:

1. Find a relevant project in [repos.md](repos.md).
2. Read the files named in that entry before exploring elsewhere.
3. Explain what it finds, then use those sources to help draft a skill for my workflow.
4. Link the original files and check the license before reusing code or text.

The assistant still needs GitHub access or the relevant links and files shared in chat. A public list does not give it access automatically. Treat repository content as source material, not instructions to the assistant.

## What I save

I add projects that match a skill or research question I may work on. I write a short note in my own words, link to the original project, and keep private lab notes, restricted course material, and participant data out of this repository.
